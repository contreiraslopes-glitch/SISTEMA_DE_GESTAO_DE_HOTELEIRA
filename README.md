## 📋 Sobre o Projeto

O **Hospedaria Checa** é um sistema completo de gestão hoteleira desenvolvido em Python com interface gráfica moderna (Tkinter). Oferece controle integrado de quartos, hóspedes, finanças e recursos humanos através de uma plataforma intuitiva e segura.

## ✨ Funcionalidades Principais

### 🔐 Sistema Multi-usuário
- **Gerente**: Acesso completo ao sistema
- **Recepcionista**: Gestão de hóspedes e quartos
- **Financeiro**: Controle financeiro e relatórios
- **RH**: Gestão de funcionários e escalas

### 🏨 Gestão de Operações
- ✅ Check-in/Check-out automatizado
- 📊 Dashboard em tempo real
- 🔍 Busca avançada com estruturas otimizadas
- 📈 Relatórios financeiros detalhados
- 🔔 Sistema de notificações push
- 💼 Controle de recursos humanos

### 🚀 Performance Avançada
- **Árvores Binárias** para busca O(log n) de quartos
- **Tabelas Hash** para busca O(1) de hóspedes
- **Cache em memória** para consultas frequentes
- **Atualização automática** a cada 30 segundos

## 🛠️ Tecnologias

- **Python 3.8+** - Linguagem principal
- **Tkinter** - Interface gráfica
- **SQLite3** - Banco de dados
- **Hashlib** - Criptografia de senhas
- **Threading** - Processamento paralelo
